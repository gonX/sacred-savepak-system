# SacredSaveStruct2 dumps

These are analysises of the individual sections saved in the save pak.

## Getting started

Running `dump-sections.py` from the base root with a compatible pak file will
generate the sections as raw files names as `dump/<section>.bin`, creating the
directory if it doesn't exist - documentation here should be respectively named
`<section>.md`
